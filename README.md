# knowledge-based-ai-assistant
An AI-powered knowledge-based assistant that answers questions using uploaded PDF and text documents.

## About the Project

This project is a knowledge-based AI system that allows users to upload documents and ask questions based on their content.

The system uses the uploaded documents as a knowledge source to generate relevant answers. For example, when a resume is uploaded, users can ask questions about the candidate's skills, education, work experience, and other information available in the resume.

## Features

- Upload PDF documents.
- Upload text documents.
- Use uploaded documents as a knowledge source.
- Ask questions about document content.
- Generate relevant answers based on uploaded knowledge.
- Support different types of document-based questions.

## How It Works

1. Upload a PDF or text document.
2. The system processes the document and uses its content as knowledge.
3. Ask a question related to the uploaded document.
4. The AI assistant generates an answer based on the available information.

## Use Cases

- Resume and CV analysis
- Document question answering
- Knowledge management
- Information extraction from documents
- Personal document assistants
- Research and learning support

## Technologies Used

The technologies and libraries used in this project will be listed here.

Python, HTML, CSS, Ollama with the gemma4:cloud 

## Usage

1. Start the application.
2. Upload a PDF or text document.
3. Enter a question about the document.
4. Review the AI-generated answer.
